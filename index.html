03 — WEB DEVELOPMENT

Built With Technology.

Three fundamental technologies behind our website.

HTML

HTML (HyperText Markup Language) digunakan untuk membuat struktur website. HTML mengatur judul, paragraf, gambar, tautan, navigasi, dan berbagai elemen halaman.

01 — STRUCTURE

CSS

CSS (Cascading Style Sheets) digunakan untuk mengatur tampilan website, seperti warna, ukuran teks, jarak, layout, efek hover, animasi, dan desain responsif.

02 — DESIGN

JavaScript

JavaScript digunakan untuk membuat website lebih interaktif, seperti animasi hujan, jam digital, tombol interaktif, dan efek ketika pengunjung menggulir halaman.

03 — INTERACTION

HOW THIS WEBSITE WORKS

HTML menjadi fondasi dan struktur website. CSS memperindah tampilan melalui warna, layout, dan animasi. JavaScript memberikan fungsi interaktif sehingga website dapat merespons aktivitas pengunjung.

Ketiga teknologi tersebut bekerja sama untuk menghasilkan website MIDNIGHT SOCIETY.

SIMPLE CODE EXAMPLE

HTML:
<h1>Hello Midnight Society</h1>

CSS:
h1 {
  color: #85b8ef;
  text-align: center;
}

JavaScript:
alert("Welcome to Midnight Society!");
